Protocolo HTTP: Requisição e Resposta

O que é o HTTP

O HTTP (Hypertext Transfer Protocol) é o protocolo de comunicação fundamental da Web. Ele estabelece as regras e o formato padrão para a troca de informações entre os navegadores e os servidores através da internet.

Cliente e Servidor

Na arquitetura da Web, o cliente (geralmente um navegador) é o dispositivo que inicia a comunicação solicitando recursos, enquanto o servidor é o sistema remoto que armazena, processa e entrega esses recursos ao cliente.

Requisição e Resposta

A comunicação ocorre por meio de um ciclo contínuo: a requisição (Request), enviada pelo cliente para solicitar uma ação ou arquivo, e a resposta (Response), devolvida pelo servidor contendo o status do processamento e os dados solicitados.

Métodos de Requisição: GET e POST

Os métodos HTTP (ou verbos) indicam a ação que o cliente deseja realizar no servidor. Os dois métodos mais utilizados na Web são o GET e o POST.

  • Método GET: Utilizado para solicitar e buscar dados do servidor. Os parâmetros são enviados visíveis na própria URL da requisição. Não deve ser usado para enviar informações sensíveis e não deve alterar o estado dos dados no servidor.
  • Método POST: Utilizado para enviar dados ao servidor para serem processados (como no envio de formulários ou criação de registros). Os dados são transportados no corpo (body) da requisição, tornando o processo mais seguro para dados sensíveis.

Exemplos de Mensagens HTTP

Exemplo de Requisição HTTP (Request)

Exemplo de uma requisição do tipo GET enviada pelo navegador para solicitar a página principal:

GET /index.html HTTP/1.1
Host: www.exemplo.com.br
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
Accept: text/html,application/xhtml+xml

Exemplo de Resposta HTTP (Response)

Exemplo da resposta enviada pelo servidor confirmando o sucesso da solicitação e entregando o documento HTML:

HTTP/1.1 200 OK
Date: Sun, 01 Nov 2026 12:00:00 GMT
Server: Apache/2.4.41 (Ubuntu)
Content-Type: text/html; charset=UTF-8

<!DOCTYPE html>
<html>
    <head><title>Página Exemplo</title></head><body><h1>Sucesso!</h1></body>
</html>

Códigos de Status HTTP

Os códigos de status são números de três dígitos retornados pelo servidor no cabeçalho da resposta para indicar o resultado do processamento da requisição.

Tabela 1: Códigos de Status HTTP
CódigoMensagem
200 OK A requisição foi bem-sucedida e o recurso solicitado foi encontrado e retornado pelo servidor.
301 Moved Permanently O recurso solicitado foi movido permanentemente para uma nova URL.
400 Bad Request A requisição possui uma sintaxe inválida ou não pôde ser entendida pelo servidor.
403 Forbidden O cliente não tem permissão de acesso ao recurso solicitado, mesmo estando autenticado.
404 Not Found O servidor não conseguiu encontrar o recurso solicitado na URL informada.
500 Internal Server Error O servidor encontrou uma condição inesperada que o impediu de atender à requisição.
