Introdução à programação WEB

Este site está sendo criado com a finalidade de aprendizagem dos alunos de programação para a internet

A Internet é a infraestrutura global de redes de computadores interconectados que permite a troca de dados. Já a Web (World Wide Web) é um sistema de informação que roda sobre a Internet, permitindo o acesso a páginas e documentos interligados por hiperlinks através de navegadores.

Conteúdos Estudados até Agora

  • Estrutura básica do HTML5
  • title: é o título que aparece no navegador
  • h1: é o título do site, o que aparece no site mesmo. diferente do título do head
  • p: parágrafos
  • ul: lista desordenada com 'li' dentro para fazer as marcações
  • ol: lista ordenada com 'li' para fazer as marcações
  • Links e navegação (a, href)
